# Contributing to Roam Control

Thanks for helping improve Roam Control.

Roam Control is maintainer-developed and is not accepting pull requests or unsolicited code contributions.

## Bugs and feature requests

Bug reports, feature requests, reproduction steps, testing results and technical findings are welcome through GitHub Issues.

When reporting a problem, please include:

- the Roam Control version and build;
- your iOS version;
- your installation method;
- what you expected to happen; and
- what actually happened.

Do not include pairing records, pairing PINs, credentials, signing material, private location information or other sensitive data.

## Technical investigation

If you have investigated a problem yourself, you are welcome to describe what you observed through an issue.

Please do not submit implementations, patches, diffs or pull requests unless specifically requested by the maintainer.

## Security

Security-sensitive reports should use GitHub Security Advisories rather than a public issue.

See [SECURITY.md](SECURITY.md).

## Distribution

Roam Control may only be distributed through channels authorised by the project owner.

Do not publish mirrors, modified builds, unofficial releases or redistributed IPA files.

See [LICENSE](LICENSE).
